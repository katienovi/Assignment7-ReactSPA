## Getting Started
1. Clone the repository.
2. Install dependencies for this project using:
```bash
    cd Assignment7-ReactSPA
    npm install
```
3. Run the server using:
```bash
    npm run dev
```
4. View the project in your browser using http://localhost:5173/
